# Mat Power Grid

This is an advanced data grid for Angular, based on the Advanced Angular Material Data Grid System by Dillyboy. It is designed to make it easy for developers to create highly advanced data grids with server-side pagination, multiple filters, and sorting with minimum effort.

**This package is currently in alpha and under active development.**

The source code and detailed documentation can be found on [GitHub](https://github.com/troyaaronjones/mat-power-grid). We recommend referring to the repository for the most up-to-date information, usage examples, and to contribute to the project.

## Installation

To install the package from npm, run:

```bash
npm install mat-power-grid
```

For more information on how to use the grid, please visit the [GitHub repository](https://github.com/troyaaronjones/mat-power-grid).
